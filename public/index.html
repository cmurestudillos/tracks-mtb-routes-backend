🚀 Guía de Inicio Rápido

  1. Regístrate: Haz una petición POST a /api/auth/signup con email, username y password
  2. Inicia sesión: POST a /api/auth/login para obtener tu token JWT
  3. Incluye el token: En cada petición protegida, añade el header Authorization: Bearer {tu_token}
  4. Explora: Usa la documentación interactiva para probar todos los endpoints

⚡ Rate Limiting

La API está protegida con rate limiting: 100 peticiones por IP cada 15 minutos. Si excedes el límite, recibirás un error 429.
